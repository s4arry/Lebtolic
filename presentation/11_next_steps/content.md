# 08 · NEXT STEP — พัฒนาข้อมูลและตรวจสอบกับกลุ่มใหม่

**ข้อความบนสไลด์**

1. ตรวจ baseline features เพิ่มจาก CDC codebook และความพร้อม ณ เวลาทำนาย
2. ศึกษา selection bias จากผู้ที่ติดตามไม่ครบ และตรวจความหมาย missing/skip codes
3. กำหนดขอบเขตการใช้งานและจำนวน false alerts ที่ยอมรับได้ก่อนเลือก threshold
4. ทดสอบโมเดลที่ freeze แล้วกับข้อมูลใหม่; ต้องมีข้อมูลที่เหมาะสมก่อนอ้างใช้กับคนไทย

**คำพูดประกอบ:** การเพิ่มข้อมูลที่เกี่ยวข้องและ external validation อาจช่วยพัฒนาได้ แต่ยังบอกไม่ได้ว่า “ปัญหาอยู่ที่ข้อมูล ไม่ใช่ algorithm” เพียงอย่างเดียว งาน nonlinear และ calibration ที่ลองแล้วไม่เพิ่มความสามารถอย่างสม่ำเสมอในข้อมูลพัฒนานี้ ไม่ได้พิสูจน์ว่า algorithm ทุกแบบช่วยไม่ได้
